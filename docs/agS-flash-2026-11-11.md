# A-only (agS) GSI flash test — 2026-11-11

The device was running the **A/B (`bgS`)** LineageOS 18.1 GSI. The correct type for the HTC Desire 12+ (A-only, non-system-as-root, vendor API 26) is **`agS`**. This test flashed the `agS` image.

## Steps
1. `adb reboot bootloader` → `fastboot boot twrp-3.7.0_9-0-brepdugl.img`
2. Backups taken in TWRP to `C:\Users\iMac2019\brepdugl\backup\`:
   - `sys24.img.gz`: old bgS system (3 GiB raw, gzip verified)
   - `ven25.img.gz`: vendor (1 GiB raw, gzip verified)
   - `boot-p21.img`: boot (64 MiB)
   Note: TWRP's `dd` rejects `bs=4M`; use `bs=1048576`.
3. Pushed `lineage-18.1-20240121-UNOFFICIAL-arm64_agS.img` (raw ext4, 2,706,898,944 B) to `/data`, then
   `dd of=/dev/block/mmcblk0p24 bs=1048576`, followed by `e2fsck -fy` and `resize2fs`.
4. Rebooted. `/data` was kept, including the unencrypted-/data fix.

## Result ✅
- `sys.boot_completed=1` about 1 minute after reboot. No factory-reset loop.
- `/system` is mounted directly from mmcblk0p24 (A-only layout: build.prop is at the image root, with no `/system/system`).
- Wi-Fi enabled, Bluetooth on, no FATAL entries in the crash buffer, vold running.
- Note: the AndyYan agS build still reports `ro.lineage.version=...arm64_bgS` in build.prop, a quirk of the builder's name string. The partition layout confirms it is the A-only image.

## Rollback
In TWRP: `gzip -dc sys24.img.gz | adb shell "dd of=/dev/block/mmcblk0p24 bs=1048576"`.
